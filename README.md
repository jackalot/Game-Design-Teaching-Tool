# Game-Design-Teaching-Tool
This tool will teach about different game design mechanics used in popular genres.
For now, it will only be mechanics in platformers.
For example, the following mechanics in order are going to be for 2D platformers specifically:
	- Flipping a run animation to save costs
	- Hold Jump to jump higher
	- Coyote time
	- Double Jump
The idea it would be showing why
these mechanics are important in 
their respective genre. This
project would explain roughly how
to implement them into a Godot project.
